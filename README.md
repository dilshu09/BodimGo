🏠 BodimGo

BodimGo is a MERN stack web application designed to connect "boarding providers" with "boarding seekers" in a simple and efficient way. The platform allows users to discover, list, and manage boarding places while providing an admin panel to oversee and control the system.

✨ Features

👤 For Users (Seekers)
- Search available boarding places
- View detailed listings with images and pricing
- Filter by location and requirements
- Contact boarding providers

🏡 For Providers
- Add and manage boarding listings
- Upload images and update details
- Control availability and pricing

🛠️ Admin Panel
- Manage users and providers
- Approve or remove listings
- Monitor platform activity


 🚀 Tech Stack

- MongoDB – Database
- Express.js – Backend framework
- React.js – Frontend library
- Node.js – Runtime environment
